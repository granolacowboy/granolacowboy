# Repository Garden Preference Rules

## Strong established rule
When an owned fork is redundant with a recoverable canonical/current upstream that is already starred, and the fork contains no meaningful unique state, prefer deleting the owned fork.

## Inherited Star Garden hypotheses
Use the live Star Garden taxonomy and evidence read-only. Prefer canonical upstreams over obsolete forks/mirrors; preserve unique or durable research; favor reusable agent, automation, knowledge, legal-tech, infrastructure, and data capabilities.
